Real attribute storage/factory/independent copy and genuine base methods replace those forwarders. Item inherits the meaningful base, having no extra documented own API. Text content's old forwarding remains unchanged and unqualified. Base setters keep independent flags and invalidate on change; apply uses actual NSView frame/alpha state. Alpha rendering keeps existing NSView behavior: backing layer opacity receives it, software-only views ignore opacity; tests do not pretend CPU/compositor alpha proof.

Inherited legacy non-keyed decoding retains false defaults for these own flags, with no new keyed-selector call or unkeyed flag-persistence claim. It is not native NIB compatibility.
