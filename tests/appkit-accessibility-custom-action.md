# Real custom accessibility action model

Existing public AppKit headers were inspected first (clean-room rung2): this class was absent, and existing chooser/element forwarding objects are not usable implementations. [Apple NSAccessibilityCustomAction](https://developer.apple.com/documentation/appkit/nsaccessibilitycustomaction?language=objc) specifies an NSObject model with name and block or target/selector. Public Objective-C variants for [name](https://developer.apple.com/documentation/appkit/nsaccessibilitycustomaction/name), [handler](https://developer.apple.com/documentation/appkit/nsaccessibilitycustomaction/handler), [target](https://developer.apple.com/documentation/appkit/nsaccessibilitycustomaction/target), [selector](https://developer.apple.com/documentation/appkit/nsaccessibilitycustomaction/selector) and the two initializers supply exact copy/copy/weak/value contracts (rung3). No Apple binary, SDK or native implementation was inspected; unchanged Firefox loader demand supplies the class name only (rung5).

The real model copies the name and BOOL(void) callback, preserves actual selector identity and uses zeroing weak target storage. Existing compiler/runtime property accessors implement the copied/atomic name/block and scalar properties. Public vendored objc_storeWeak/objc_loadWeak implement manual-reference-counting weak access; weak loads retain/autorelease the result and deallocation unregisters the slot. Initializer exceptions release partial state before propagating. No private perform selector, fake default action success, extra copy/archive protocol or guessed setter cross-clearing is added.

This implements the action object's public model, not an accessibility server. The current framework does not expose these actions through an assistive bridge/VoiceOver/AT-SPI or a functioning element-level custom-action list. Tests deliberately use their own typed consumer to invoke the returned real block or their own target method and verify actual BOOL results and effects. No native selector argument conventions are borrowed from UIKit, and no native invalid-input/nil exception policy is inferred.

Original before-capable runtime source links only Foundation and dlopens actual AppKit. NSWindow class metadata and real AXPopover data are positive controls, with no window or stub method invoked. The stage18 coordinator before passes those controls then fails missing public custom-action class: exit1 in1.642527692s/shutdown0 (accessibility-custom-action-before.json).

Prepared functional gates cover mutable-name copies; copied stack block and object capture after helper/creation-pool return; actual true/false callback effects; callback/name self replacement, clearing and captured-object release; target/SEL storage and own typed invocation; zeroing after last target owner release; no strong ownership of target; callback release and weak-slot cleanup sequence when the action dies first. Getter observation pools account for autoreleased retained loads instead of falsely diagnosing ownership. The independent header TU imports direct/umbrella declarations and asserts actual NSString, BOOL-block, NSObject-protocol and SEL types.

The production source compiles into isolated x86_64+i386 fat output using the existing AppKit compile recipe with candidate source/header substitution. Runtime/header TUs compile; source-list and umbrella changes are explicit. Shared configuration/build/stage and guest launches remain coordinator-owned. Candidate runtime, element dispatch, complete Firefox startup, UI and app workflow remain unqualified until measured.
