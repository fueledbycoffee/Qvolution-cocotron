# Real Fontconfig pattern instance loading

Legacy NSFont names can be Fontconfig patterns, as this backend's historical font catalog exposes them. The old filenameForPattern path retains only FC_FILE and calls FT_New_Face with index0. It therefore silently loads a default face even when Fontconfig matches a real named instance or collection face. The correction reuses the existing typed FILE/INDEX loader via a factored matching helper; legacy patterns accept nonUnicode faces as before, while existing coverage/UI matching keeps its Unicode requirement. ExactPS selection still errors explicitly on contradictory configured metadata and never falls back after a known exact match fails. Pattern parsing/matching failures returnnil with an initialization diagnostic. Host passthrough receives the actual matched native path; no new aliases or host settings are created.

Native fontconfig-pattern-instances.py --baseline8d337156 extracts the actual old filenameForPattern Cmatching calls and initializer FT_New_Face(...,0) statement. The adapter supplies CString transport in place of NSString UTF8/fileSystemRepresentation, and inputfiles satisfy the original existence guards. It is not execution of the complete ObjC API. Each case independently verifies actual Fontconfig matchedINDEX before invoking the adapted loader. Private config contains only explicit open Ubuntu Roman/Italic files. Regularcontrol passes; Bold, BoldItalic and CondensedBold fail actualPS/index/Wmetrics (three failures). Candidate extracts wholeactual Cmatching/typedload helper bodies and allfour cases pass ASan/UBSan. Existing exactPS/TTC/invalidindex/error/nonUnicode and UIFont16source tests pass after mechanical extractor dependency updates.

The original public appkit-pattern-font-instance.m fixture uses actual NSFont/CTFont and validates exactPS reference metrics before each pattern assertion. Run it with a caller-owned private FONTCONFIG_FILE selecting only openUbuntu/DejaVu fonts; native and guest environment must both receive that configuration. No global host fontconfig settings change. Root owns real guest before/after, no public runtime pass is inferred from native adapters or compilation. Wmetrics/PS controls identify current installedopen inputs, not arbitrary version-independent values. Private policy is needed because user aliases can legitimately substitute other families. Exact PostScript API behavior, matrix/bitmap/variableaxis editing and fulltext/rendering acceptance remain separate.

Provenance: existing typed file/index matching source and headers (rung2), FreeType public face_index/named-instance contract https://freetype.org/freetype2/docs/reference/ft2-face_creation.html and Fontconfig matching API https://fontconfig.pages.freedesktop.org/fontconfig/fontconfig-devel/ (rung3), original actualsource/native private-config observations (rung4). This repairs existing implementation pattern routing, not an assertion that arbitrary Fontconfig pattern strings are native Apple font names. No vendor binary implementation or font assets copied.
