# Catalog opacity runtime contract

Apple's [colorWithAlphaComponent:](https://developer.apple.com/documentation/appkit/nscolor/withalphacomponent(_:)) specifies a new color with the same color space/component values and the requested opacity, and [alphaComponent](https://developer.apple.com/documentation/appkit/nscolor/alphacomponent) describes the actual opacity. The existing catalog class inherited an opacity getter of1 and returned nil for opacity<1, even when its backing was translucent. This is distinct from placeholder-role palette policy.

The focused fix forwards opacity to the actual backing and derives a new catalog wrapper preserving named space/catalog/role metadata. Its backing is modified through the existing component/dynamic provider implementation; derived colors bypass semantic role reapplication so the requested dark alpha is not reset. An internal optional alpha override distinguishes derived opacity identity; equality/hash agree for equivalent overrides, while source remains unchanged. This is an original internal representation, not an inferred Apple private field. Replacement is not repeated multiplication, and copy ownership retains dynamic backing/providers.

Original appkit-catalog-alpha.m links AppKit/CoreGraphics, needs no arguments/NSApplication/window. It compares a real translucent secondary label catalog's getter to actual CG alpha, requires returned named variants, equality/hash/metadata, unchanged source, actual transparent CPU pixels, replacement not multiplication, dynamic Dark/Aqua/nested-scope drawing after creation pool drain and replacing an already derived alpha. Broad pixel tolerances cover existing integer rounding, not native snapshots.

## Explicit NSCoding limit

Existing NSColor.encodeWithCoder's named-space branch writes only catalog/name and contains a FIXME for the backing NSColor; decoder case6 reads an optional backing NSColor. This lane does not invent new archive keys or change that existing path. The new runtime alpha override is not serialized, so alpha-variant archive roundtrip remains unsupported; no full NSCoding/cross-process color fidelity claim is made. It needs a separately specified/reproduced correction. Pattern-color opacity, invalid/out-of-range alpha inputs and arbitrary custom backend color implementations are not qualified by this fixture.

Coordinator parent baseline: exit1 in1.666s with exact-prefix shutdown0, getter mismatches actual backing alpha and variant creation returns nil (logs/catalog-alpha-before.json). Variant pixels/lifetime could not be observed before because variants were absent; candidate runtime is needed to qualify those paths. Isolated source/fixture compilation passes; independent inspector source review found no concrete blocker; candidate guest remains pending.
