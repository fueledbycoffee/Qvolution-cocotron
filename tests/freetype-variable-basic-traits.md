# Actual variable-font basic trait regression

The public original appkit-ubuntu-variable-traits client accepts traits, manager, catalog, convert or inspector. It loads exact installed open Ubuntu-Regular, Ubuntu-Bold and UbuntuItalic-BoldItalic atsize1000 and rejects substituted/default instances using actualPS plus independent nativeFT observed W924/942/931 design-unit advances. Those current inputfont identities/metrics are version-specific guards, not general font rules. The inspector mode drives actual own controls and checks selected/unselected font identity. Root owns guest before/after and user acceptance; no candidate AppKit/CT runtime pass is claimed from host tests.

Native freetype-variable-basic-traits.py extracts the actual O2FontGetFaceStyleFlags source and calls real FreeType over exact open DejaVu static faces and Ubuntu namedinstances. --baseline OWN_COMMIT instead extracts the actual old own CTFontGetSymbolicTraits C body with a minimal direct-face bridge; this is a source-level scalar-logic regression, not full CoreText execution. Baseline1f9e7176 yields3targetfailures for UbuntuBold/CondensedBold/BoldItalic; staticDejaVu, UbuntuRegular/Medium controls pass. Candidate9cases pass with ASan/UBSan, repeated lookup and unchanged nativeflags. LeakSanitizer cannot run under this host's tracing environment; detect_leaks=0 is explicit, no leak-sanitizer pass is claimed.

make-variable-style-vector.py builds an entirely original two-glyph SFNT with wght/ital/slnt axes and a valid emptygvar table using fontTools. Generate into private scratch (no generatedfontbytescommitted), then pass --vector FILE to the native test. Eight additional realFT current-coordinate cases check weight699/700 boundary, italic0/1, negative/positive slant and returningtoRoman. Actual source error-injection adapters forward to real FT by default: coordinate-allocation/MM-query/design-coordinate failure must returnNO without changing calleroutput and release owned MMmetadata when acquired. A small synthetic nonSFNTMM struct tests only the guard that preserves raw flags without OpenType interpretation; it does not qualify AdobeType1MM fonts. Existing UIFont16case source test uses a private Fontconfig config containing explicit openDejaVu/Ubuntu fonts; PS/TTC/error tests retain their original controls.

Implementation reuses real current FT_Get_Var_Design_Coordinates metadata, never PS/style-name heuristics or synthetic outlines. It is restricted to SFNT GX/OpenType variationfonts: AdobeMM design coordinates use a different whole-number/arbitraryscale and retain existingrawB/I behavior. Cached basicflags are computed once before O2Font publication; CT trait queries read the immutable scalar, so they do not allocate FT variation metadata on every query. Metadata enumeration/UI selection/coverage ranking share the same actualface helper at creation/selection time. No public variationmutation API is implemented here; later axisediting must update both actualface and cache.
